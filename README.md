# Unicorn Hunt v4.0

Telegram-игра на aiogram 3 + SQLite + Pillow: охота, коллекционирование уникальных экземпляров, исследование трёх локаций, погода, мировые события, наживки, достижения, задания, рейтинги и Telegram Stars.

## Основной цикл

Игрок пишет `единорог` или использует `/menu`. Бесплатная охота доступна раз в 10 минут. Результат: поимка, найденная наживка или поиск без добычи. Неудачи постепенно повышают шанс следующей встречи. Отдельный rarity pity помогает после долгой серии обычных поимок, а duplicate protection снижает вероятность одного и того же вида подряд.

## Контент

- 3 локации;
- 27 видов: 24 основных + 3 секретных;
- 4 наживки;
- динамическая общая погода;
- глобальные события;
- редкий «Древний зов» — два двухчасовых окна в неделю;
- отдельные экземпляры со своим ростом, рогом, возрастом, окрасом, характером и качеством.

Секретные виды требуют комбинаций условий: исследование, уровень, особая погода, редкая наживка, время суток, серия неудач или глобальное событие. Обычному игроку они не показываются в бестиарии до первой поимки.

## Качество экземпляров

В БД сохраняется числовой score для внутреннего сравнения и обратной совместимости. Игрок видит только словесную градацию:

Обычный → Хороший → Отличный → Превосходный → Великолепный → Выдающийся → Исключительный → Безупречный.

После охоты бот отдельно отмечает новый вид, новый лучший экземпляр вида и личный рекорд.

## Сезоны

Каждый календарный месяц — отдельный сезон. `/season` показывает:
- топ-10 по числу поимок;
- топ-10 по престижу коллекции (редкость + качество);
- архив предыдущих сезонов;
- сезонные отметки и награды топ-10 в профиле.

## Задания и streak

`/quests` показывает 3 ежедневных и 4 недельных задания. Награды — XP и иногда наживки — начисляются автоматически. `hunt_days` хранит дни активности и позволяет считать текущую и рекордную серию.

## Команды игрока

- `/start` — введение;
- `/menu` — inline-меню;
- `/help` — полная инструкция;
- `/profile` — расширенная статистика;
- `/inventory` — коллекция;
- `/bestiary` — бестиарий;
- `/locations` — локации;
- `/bait` — наживки;
- `/quests` — задания;
- `/achievements` — достижения;
- `/world` — погода и глобальные события;
- `/top` — глобальный/локальный топ-10 за всё время или 24 часа;
- `/season` — сезонные рейтинги;
- `/starhunt` — дополнительная охота за 1 Telegram Star;
- `/claimstar` — восстановление оплаченной, но не исполненной охоты;
- `/terms`, `/paysupport` — платежная информация.

## Админ и тестирование

По умолчанию `@edgeel` считается тестовым администратором. Рекомендуется также указать числовой ID в `ADMIN_IDS`.

Основные команды:
- `/admin`;
- `/test` — sandbox без сохранения результата;
- `/admin_stats`;
- `/admin_user @username`;
- `/admin_setlevel @username 30`;
- `/admin_setresearch @username all 100`;
- `/admin_givebait @username dew 5`;
- `/admin_resetcooldown @username`;
- `/admin_species`;
- `/admin_spawn species_id`;
- `/admin_forceweather Название погоды`.

## База данных

Основные старые таблицы не удаляются. v4.0 автоматически добавляет:
- `hunt_events` — подробный event-log новых охот;
- `hunt_days` — дни активности;
- `quest_claims` — уже выданные награды заданий;
- `season_awards` — сезонные отметки;
- `test_settings` — sandbox-настройки администратора.

В `players` добавляются `rarity_pity`, `last_unicorn_id`, `duplicate_streak`, `is_admin`.

Исторические данные сохраняются. Детальная статистика, для которой старые версии не хранили события (например, число всех охот за конкретные прошлые сутки), начинает полноценно накапливаться после обновления до v4.0.

## Обновление со старой версии

Остановить процесс бота, сделать резервную копию `unicorns.db`, заменить файлы кода и снова запустить. Не заменять существующие `unicorns.db` и `.env`. `init_db()` самостоятельно выполняет безопасные `CREATE TABLE IF NOT EXISTS` и `ALTER TABLE` для новых полей.
